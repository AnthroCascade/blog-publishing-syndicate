# Verification

## Verification levels

1. **Unverified:** No attempt to check
2. **Plausible:** Consistent with known facts, not contradicted
3. **Corroborated:** Multiple independent sources agree
4. **Verified:** Traced to primary source, confirmed accurate

Know the level. Report it honestly.

## Red flags

- Circular sourcing (A cites B cites A)
- Orphan statistics (numbers without methodology)
- Dead links (source no longer accessible)
- Misattribution (quote assigned to wrong person)
- Context stripping (true quote, false implication)

## Uncertainty language

- "Verified" — traced to source, confirmed
- "Corroborated" — multiple sources agree
- "Reported" — source says this, not independently confirmed
- "Claimed" — assertion without supporting evidence
- "Unverified" — not yet checked

Use the right word. Each carries different weight.

## Requires

- web-fetch: access sources to verify claims
- web-search: find corroborating or contradicting evidence

Fortes drawing on verification inherit these requirements. Environment must provide.
