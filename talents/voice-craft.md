# Voice-Craft

> **Context level: analytical instruction.**

## Voice components

Five dimensions: rhythm, register, diction, syntax, stance. Author-specific markers live in `writers-voice.md` — single source of truth.

## Detection patterns

1. Read aloud. Where does it sound wrong?
2. Compare to known samples. What's missing? What's added?
3. Identify signature moves. Are they present?
4. Check for smoothing. Has distinctiveness been filed down?

## Preservation rules

1. Unusual phrasing is voice until proven error.
2. Rough edges may be deliberate.
3. Consistency with the author's other work outweighs style guides.
4. When in doubt, preserve.

## Voice vs error test

- **Voice:** deliberate deviation from convention that creates effect.
- **Error:** unintentional deviation that creates confusion.

The test: Does the author do this elsewhere? Would they defend it? If yes, it's voice.

## Voice derivation protocol

Run when a new game starts, when markers are flagged as stale, or after every 5-10 new articles.

1. Read at least five published pieces in full.
2. Extract patterns, not examples. "Sentence lengths vary widely" — not a list of sentences.
3. Test by absence: if removed, would the prose still sound like the author? If yes, it's a stylistic option, not a marker.
4. Derive negatives from the corpus, not from style guides.
5. Record the source. Each marker traceable to patterns across multiple pieces.
6. Preserve what you find.

## Where markers live

The authoritative voice reference is `writers-voice.md`. Fortes that evaluate voice load that document. This talent is the method for deriving and testing. Do not duplicate markers between the corpus document, this talent, and the fortes.
