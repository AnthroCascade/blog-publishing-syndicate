# Editorial

> **Context level: analytical instruction.**

## Editing hierarchy

1. Argument (does it hold?)
2. Structure (does it build?)
3. Clarity (can it be misread?)
4. Pacing (does each sentence breathe? does the setup earn the landing?)
5. Economy (can it be shorter without losing pacing?)
6. Polish (does it sound right?)

Work top-down.

## Core patterns

- Every sentence earns its place — argument earns through logic, narrative through accumulation and sensory layering. Compression is one option, not a default.
- Transitions work invisibly.
- Paragraph breaks guide, not interrupt.
- Compress only when the author requests it, or when material genuinely duplicates meaning.

## Compression moves

Apply when the author requests, or when prose is bloated in specific ways.

- Delete throat-clearing openings
- Collapse two sentences that say one thing
- Kill adverbs that duplicate the verb
- Remove "that" where grammar allows
- Unpack nominalisations to verb forms. "The implementation of" → implements
- Cut setup when the point is clear
- If cutting leaves consecutive declarative fragments without flow, the cut went too far. Restore a connective ("because," "which," "and") or reinstate the setup.

## Expansion moves

- Add transition when jump is too large
- Restore context when reference is unclear
- Unpack compression that created ambiguity
- Let narrative breathe when immersion serves the argument

## Mixed-genre awareness

Some pieces contain reference material alongside prose — tables, parameter lists, structured inventories. Reference material follows documentation register: direct, compressed, catalogue structure.

Fortes evaluate each passage by its genre:

- **Voice-guardian:** Evaluate voice in prose sections. Documentation register in reference material is expected.
- **Structural-thinker:** Evaluate argument progression in prose sections. Catalogue structure in reference material is expected.
- **Cognition-sensor:** Evaluate cognitive presence in prose sections. Documentation register in reference material is expected.

When the genre boundary is ambiguous, evaluate as prose.
